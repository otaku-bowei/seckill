│  ═════════════════════════════════════════             │

│  - Redis Lua 要求所有key必须在同一个node                │
│  - 否则报错: CROSSSLOT Keys in request...             │
│                                                         │

### 2. Hash Tag 解决方案

```
┌─────────────────────────────────────────────────────────┐
│  Hash Tag: 用 {} 包裹的关键字，slot计算只看 {} 内内容     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  不用Hash Tag:                                          │
│    "sku:stock:1"   → slot=1234                          │
│    "user:buy:1"    → slot=5678  ← 不同node!             │
│                                                         │
│  用Hash Tag:                                            │
│    "{s1}:stock"    → slot=1000                          │
│    "{s1}:user"     → slot=1000  ← 同一node ✓            │
│                                                         │
│  ═════════════════════════════════════════             │
│                                                         │
│  我们的key改为:                                         │
│    "{seckill:1}:stock"     → 都走同一slot               │
│    "{seckill:1}:user:123"  →                          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
