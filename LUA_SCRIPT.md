# Lua脚本详解

## 当前实现的Lua脚本

```lua
local stock_key = '{' .. KEYS[1] .. '}:stock:' .. ARGV[1]
local user_key = '{' .. KEYS[1] .. '}:user:' .. ARGV[1] .. ':' .. ARGV[2]

-- 检查用户是否已抢购
if redis.call('EXISTS', user_key) > 0 then
    return -1
end

-- 检查库存
local stock = redis.call('GET', stock_key)
if not stock or tonumber(stock) < tonumber(ARGV[3]) then
    return -2
end

-- 扣减库存并设置用户标记
redis.call('DECRBY', stock_key, tonumber(ARGV[3]))
redis.call('SET', user_key, ARGV[3], 'EX', 86400)

return 1
```

## 参数说明

| 参数 | 含义 | 示例值 |
|------|------|-------|
| KEYS[1] | skuId | 1 |
| ARGV[1] | skuId (重复传) | 1 |
| ARGV[2] | userId | 123 |
| ARGV[3] | quantity | 1 |

## 执行流程图

```
┌─────────────────────────────────────────────────────────────┐
│  输入: KEYS=[1], ARGV=[1, 123, 1]                   │
│  即: skuId=1, userId=123, quantity=1                │
└─────────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 构建key (加Hash Tag)                        │
├─────────────────────────────────────────────────────────────┤
│  stock_key = "{1}:stock:1"                           │
│  user_key = "{1}:user:1:123"                        │
│                                                     │
│  效果：两个key都在同一slot ✓                        │
└─────────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 检查是否已抢购 (防重复)                   │
├─────────────────────────────────────────────────────────────┤
│  EXISTS "{1}:user:1:123"                            │
│                                                     │
│  如果存在 → return -1 (已抢购过)                   │
└─────────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 3: 检查库存是否足够                          │
├─────────────────────────────────────────────────────────────┤
│  GET "{1}:stock:1" → "10"                        │
│                                                     │
│  如果 stock < quantity → return -2 (库存不足)          │
│  如果 stock >= quantity → 继续                          │
└─────────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 4: 扣减库存 + 标记用户 (原子操作)           │
├─────────────────────────────────────────────────────────────┤
│  DECRBY "{1}:stock:1", 1  → stock变成9              │
│  SET "{1}:user:1:123", "1", EX=86400              │
│  (用户标记保存一天)                                │
│                                                     │
│  return 1 (成功)                                 │
└─────────────────────────────────────────────────────────────┘
```

## 返回值含义

| 返回值 | 含义 | HTTP状态码 |
|--------|------|-----------|
| 1 | 抢购成功 | 200 |
| -1 | 已抢购过 | 400 |
| -2 | 库存不足 | 402 |
| null | 系统错误 | 500 |

## 关键点

1. **Hash Tag**: `{KEYS[1]}` 让 stock_key 和 user_key 强制在同(slot
2. **先CHECK后操作**: 先检查用户和库存，都OK再扣减
3. **原子操作**: 整个Lua脚本一次性发给Redis，中间不被插入
4. **SET EX 86400**: 用户标记24小时过期
